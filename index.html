Revelio – Static Forensic PDF Scanner

Personal Project · Deployed

A static forensic scanner that surfaces what a PDF hides from a reader – recoverable hidden text, objects that can act on your machine, changes made after the document was finalised, and what it declares about its own origin.

PythonPyMuPDFC2PApytestGitHub ActionsRender
  • Hidden text: flags text under redaction fills, invisible/vanishing-colour spans (contrast-aware – samples rendered pixels so white-on-header is ignored), sub-4pt microfont, and OCR-layer text hidden under scanned black bars
  • Structural risk: detects /JavaScript, /Launch, /OpenAction, /EmbeddedFile and more via PyMuPDF (sees compressed object streams) plus a raw-byte pass that catches hex-obfuscated names
  • Revision diffing: reconstructs each incremental-update revision at successive %%EOF markers and diffs them to reveal content added or removed after the original save
  • Provenance: reports AI/generator metadata, XMP markers and C2PA Content Credentials – with c2pa-python it cryptographically validates each manifest and flags tamper (INVALID) or forged signatures
  • Shipped: CLI with JSON output and CI exit codes, a drag-and-drop web UI (stdlib only – the PDF never leaves the machine), one-click Render deploy, and 14 behavioural tests running on every push via GitHub Actions
